# homebrew-tap

Homebrew tap for [TomTonic](https://github.com/TomTonic) tools.

```bash
brew install TomTonic/tap/extract-sbom
```

Formulas here are generated and published automatically by each tool's
own release workflow (via GoReleaser) - see the respective tool's repo
for details, e.g. [TomTonic/extract-sbom](https://github.com/TomTonic/extract-sbom).
